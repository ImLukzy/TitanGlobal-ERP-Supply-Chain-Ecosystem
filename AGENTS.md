# AGENTS.md

Las reglas de este repositorio están en `CLAUDE.md` y valen para cualquier agente (Codex, OpenCode, Antigravity…). Léelo antes de empezar, junto con:
- `docs/contexto-proyecto.md`: el contexto completo y el estado actual del proyecto.
- `docs/enunciado.md`: lo que se evalúa (Lab 08 / Examen).
- `docs/arquitectura.md`: los 80 módulos, los contratos, las desviaciones decididas y el frontend.
- `docs/equipo/equipo.md` y `docs/equipo/lecciones.md`: flujo del equipo y errores que no hay que repetir.
- La spec de tu encargo en `docs/specs/`.
